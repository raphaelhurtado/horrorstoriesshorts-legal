# HorrorStories

HorrorStories automatically creates and shares AI-generated, short-form horror story videos to TikTok.

This repository hosts the legal and support pages for the HorrorStories TikTok app.

Privacy Policy: https://raphaelhurtado.github.io/horrorstoriesshorts-legal/privacy-policy.html

Terms of Service: https://raphaelhurtado.github.io/horrorstoriesshorts-legal/terms-of-service.html

## About the app

HorrorStories uses the TikTok API for Developers (Login Kit and Content Posting API) to let creators automatically publish AI-generated horror short videos to their own TikTok profile.
